# tests/canaries.txt is 47 hand-picked names. This is the same check with three orders of magnitude
# more coverage, and it found something the short list could not: `lnkd.in`, LinkedIn's URL
# shortener, sitting bare in malicious/ek_clearfake-1.txt in a sorted block of campaign domains it
# had been bulk-imported with.
#
# WHY THE TOP 10k AND NOT DEEPER. These lists rank by DNS query volume, so the further down you go
# the more live malware they contain - correct to list, and reported here as a finding. The head is
# the segment where that is rare. Deeper passes are misc/alexa1m.py's job, with its curated IGNORE
# set, on a workstation rather than in CI.
#
# WHY suspicious/ IS NOT GATED ON THIS. Those piles exist TO name popular services whose use is
# itself the signal - ddns.net, duckdns.org, ngrok.io, wix.com, ipify.org, f2pool.com. Measured, 68
# of 70 literal hits are there and every one is a correct trail. Gating them would mean 68 standing
# findings, which is an alarm muted on its first day.
#
# WHY IT IS NOT REFRESHED BY A ROBOT. A stale canary list is wrong in the harmless direction: a
# domain that was in the top 10k six months ago is still one that must never be flagged. Measured
# churn is 15.6 per cent over six months, and all staleness costs is coverage of names that became
# popular since - a slowly widening gap, not a wrong answer. Regenerate by hand when it feels thin:
#
